## 7. 高度な同期処理 - concurrent.Lock

- Javaにおける高度な同期処理と、`java.util.concurrent.locks`パッケージの基本概念について学習
- `synchronized`によるモニターロックと、明示的なロック制御の違いについて学習
- `LockSupport`クラスの基本概念と、スレッドの待機・再開を制御する仕組みについて学習
- `LockSupport.park()`を使用して、現在実行中のスレッドを待機させる方法について学習
- `LockSupport.unpark(Thread)`を使用して、指定したスレッドに実行再開の許可を与える方法について学習
- `park()`による待機では、スレッドが通常`WAITING`状態になることについて学習
- `parkNanos()`を使用して、時間制限付きの待機を実行する方法について学習
- `LockSupport`がスレッドごとに管理する許可証（Permit）の基本概念について学習
- `unpark()`を`park()`より先に実行した場合でも、許可証を利用して待機せずに処理を進められる仕組みについて学習
- 許可証はスレッドごとに最大1つ保持され、`unpark()`を複数回呼び出しても蓄積されないことについて学習
- `park()`は許可証の付与、割り込み、その他の理由によって復帰する場合があることについて学習
- `park()`による待機中に割り込みが発生した場合の動作について学習
- `Thread.sleep()`と`LockSupport.park()`の割り込み処理の違いについて学習
- `LockSupport`はスレッドの待機・再開を制御する仕組みであり、それ自体は排他制御を行わないことについて学習
- `ReentrantLock`クラスの基本概念と、明示的なロックを使用した排他制御について学習
- `ReentrantLock`の`lock()`と`unlock()`を使用して、ロックの取得と解放を行う方法について学習
- ロックを取得できないスレッドが、ロックの解放を待機する仕組みについて学習
- `ReentrantLock`によるロック待機では、スレッドが通常`WAITING`状態になることについて学習
- `ReentrantLock`が再入可能（Reentrant）なロックであることについて学習
- 同じスレッドが同じロックを複数回取得できる仕組みについて学習
- ロックの取得回数に対応して`unlock()`を実行する必要があることについて学習
- `try-finally`を使用して、例外が発生した場合でも確実にロックを解放する方法について学習
- `tryLock()`を使用して、ロックの取得を試み、取得できない場合は待機せずに別の処理へ進む方法について学習
- 時間指定の`tryLock()`によって、ロックの取得待ちにタイムアウトを設定する方法について学習
- 公平ロック（Fair Lock）と非公平ロック（Non-fair Lock）の基本概念について学習
- `ReentrantLock(true)`を使用して、公平性を考慮したロックを生成する方法について学習
- 公平ロックでもスレッドの実行順序が完全に保証されるわけではないことについて学習
- `lock()`によるロック待機と、`lockInterruptibly()`による割り込み可能な待機の違いについて学習
- `lockInterruptibly()`を使用して、ロック取得待ちのスレッドに対する割り込みを処理する方法について学習
- `lockInterruptibly()`の待機中に割り込みが発生すると、`InterruptedException`がスローされることについて学習
- `lock()`による待機中に割り込みが発生しても、割り込みだけではロック取得待ちを中断しないことについて学習
- `synchronized`と`ReentrantLock`を比較し、ロック取得・解放・待機・割り込みへの対応の違いについて学習
- `LockSupport`と`ReentrantLock`の仕組みを通して、スレッドの待機制御と排他制御の違いについて理解を深めた
