## 1. プロセスとスレッドの概要

- マルチタスクの基本概念と、複数のタスクを並行して処理する仕組みについて学習
- マルチプロセスの基本概念と、複数のプロセスを実行する仕組みについて学習
- プロセスとスレッドの違いを比較し、それぞれの役割と特徴について学習
- プロセスが独立したメモリ空間を持つ仕組みについて学習
- 一つのプロセス内で複数のスレッドを実行するマルチスレッドの仕組みについて学習
- 同一プロセス内のスレッドがヒープ領域などのメモリを共有する仕組みについて学習
- スレッドごとに独立したスタック領域を持つことについて学習
- 並行処理（Concurrency）と並列処理（Parallelism）の基本概念と、その違いについて学習
- CPUコアとスレッドの関係を理解し、複数のスレッドがCPUを利用する仕組みについて学習
- OSによるスレッドスケジューリングの基本概念と、スレッドの実行順序が決定される仕組みについて学習
- タイムスライスによってCPUの実行時間を分割し、複数のスレッドを切り替えながら実行する仕組みについて学習
- コンテキストスイッチの基本概念と、スレッドの実行状態を保存・復元する仕組みについて学習
- コンテキストスイッチに伴う処理コストと、スレッド数を増やしても必ずしも処理性能が向上しない理由について学習
- マルチスレッド環境ではスレッドの実行順序が保証されないことについて学習
- プロセスとスレッドの基本構造を通して、Javaにおけるマルチスレッド処理の基礎について理解を深めた

## 2. スレッドの生成と実行

- Javaにおけるスレッドの生成方法と、複数のスレッドを実行する基本的な仕組みについて学習
- `Thread`クラスを継承し、`run()`メソッドをオーバーライドして処理を定義する方法について学習
- `start()`メソッドを使用して新しいスレッドを開始する仕組みについて学習
- `start()`と`run()`を直接呼び出す場合の違いについて学習
- `main`スレッドと新しく生成したスレッドが、それぞれ独立して処理を実行する仕組みについて学習
- スレッドの実行順序は保証されず、実行するたびに処理結果の順序が変わる可能性があることについて学習
- `Thread.currentThread()`を使用して現在実行中のスレッドを取得する方法について学習
- `getName()`を使用してスレッド名を取得し、どのスレッドが処理を実行しているか確認する方法について学習
- デーモンスレッド（Daemon Thread）の基本概念と、バックグラウンド処理における役割について学習
- `setDaemon(true)`を使用してデーモンスレッドを設定する方法について学習
- 一般スレッド（User Thread）とデーモンスレッドの違いを比較し、一般スレッドがすべて終了するとJVMが終了可能になる仕組みについて学習
- `Runnable`インターフェースを実装し、`run()`メソッドに実行処理を定義する方法について学習
- `Runnable`の実装オブジェクトを`Thread`に渡してスレッドを生成する方法について学習
- `Thread`クラスの継承と`Runnable`インターフェースの実装を比較し、処理内容とスレッドの実行管理を分離する利点について学習
- スレッド名や経過時間などを出力するログユーティリティを作成し、マルチスレッド環境での実行状況を確認する方法について学習
- 複数のスレッドを生成して同時に開始し、それぞれの処理が独立して進行する様子について学習
- 匿名クラスやラムダ式を使用して`Runnable`を実装する方法について学習
- `Runnable`のさまざまな実装方法を比較し、ラムダ式によって簡潔にスレッド処理を記述できることについて学習
- スレッドの生成から実行までの流れを通して、Javaにおけるマルチスレッドプログラミングの基本的な実装方法について理解を深めた
