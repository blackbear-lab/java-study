## 1. Objectクラス

- Javaのすべてのクラスの最上位にある`Object`クラスについて学習
- `Object`型を利用した多態性とダウンキャストについて学習
- `toString()`によるオブジェクト情報の表現について学習
- `==`と`equals()`による同一性・同値性の違いについて学習

## 2. 不変オブジェクト

- 基本型と参照型における値・参照の共有について学習
- 共有参照によって発生する副作用（Side Effect）について学習
- 状態を変更できない不変（Immutable）オブジェクトの特徴について学習
- 値を変更する代わりに新しいオブジェクトを生成する方法について学習

## 3. Stringクラス

- `String`の基本構造、String Pool、文字列の比較について学習
- `String`の不変性と主要な文字列操作メソッドについて学習
- `StringBuilder`を利用した効率的な文字列操作について学習
- メソッドチェイニングの仕組みについて学習

## 4. ラッパークラス・Classクラス

- 基本型とラッパークラス、ボクシング・アンボクシングについて学習
- `valueOf()`、`parseInt()`などラッパークラスの主要メソッドについて学習
- `Class`クラスを利用したクラス情報の取得について学習
- `System`、`Math`、`Random`クラスの基本的な使用方法について学習

## 5. 列挙型 - ENUM

- 文字列による値管理の問題点と型安全性について学習
- 型安全な列挙型パターンと`enum`の基本構造について学習
- `values()`、`valueOf()`、`name()`などEnumの主要メソッドについて学習
- Enumにフィールドやメソッドを持たせ、条件分岐を整理するリファクタリングについて学習

## 6. 日付と時刻

- `LocalDate`、`LocalTime`、`LocalDateTime`を利用した基本的な日付・時刻の扱いについて学習
- `ZonedDateTime`、`OffsetDateTime`、`ZoneId`を利用したタイムゾーンの扱いについて学習
- `Instant`を利用した機械中心の時刻表現について学習
- `Duration`、`Period`を利用した時間・期間の差の計算について学習
- `ChronoUnit`、`ChronoField`を利用した日付・時刻の単位やフィールドの扱いについて学習
- `plus()`、`minus()`、`with()`を利用した日付・時刻の操作について学習
- `isSupported()`を利用したフィールド対応可否の確認について学習
- `DateTimeFormatter`を利用した日付・時刻のフォーマットとパースについて学習

## 7. ネストクラス・内部クラス1

- クラスの中にクラスを定義するネストクラス（Nested Class）の基本構造と種類について学習
- `static`を付ける静的ネストクラスと、外側クラスのインスタンスに所属する内部クラスの違いについて学習
- 静的ネストクラスから外側クラスの静的メンバーへアクセスする方法について学習
- 内部クラスから外側クラスのインスタンスメンバーへアクセスする方法について学習
- ネストクラスを利用した論理的なグループ化とカプセル化について学習
- 内部クラスを利用して不要なGetterを減らし、外部への情報公開を抑える方法について学習
- 同名の変数が存在する場合のシャドーイング（Shadowing）と`this`、`外側クラス名.this`によるアクセス方法について学習

## 8. ネストクラス・内部クラス2

- メソッドなどのコードブロック内に定義するローカルクラス（Local Class）について学習
- ローカルクラスから外側のローカル変数へアクセスする方法について学習
- ローカル変数のライフサイクルと変数キャプチャ（Variable Capture）の仕組みについて学習
- `final`または実質的に`final`（Effectively Final）な変数だけをキャプチャできる理由について学習
- クラス名を定義せず、オブジェクトの生成と同時に実装する匿名クラス（Anonymous Class）について学習
- 匿名クラスを利用して一度だけ使用する実装を簡潔に記述する方法について学習
- インターフェースと匿名クラスを利用して、共通処理と変更される処理を分離する方法について学習

## 9. 例外処理1 - 理論

- 例外処理が必要な理由について学習
- エラー状況を作成し、エラー処理がない場合の問題点について学習
- 戻り値を利用したエラー処理とその限界について学習
- Javaの例外階層について学習
- Javaにおける例外処理の基本ルールについて学習
- チェック例外（Checked Exception）の特徴と処理方法について学習
- 非チェック例外（Unchecked Exception）の特徴と処理方法について学習
