## 1. Objectクラス

- Javaのすべてのクラスの最上位にある`Object`クラスについて学習
- `Object`型を利用した多態性とダウンキャストについて学習
- `toString()`によるオブジェクト情報の表現について学習
- `==`と`equals()`による同一性・同値性の違いについて学習

## 2. 不変オブジェクト

- 基本型と参照型における値・参照の共有について学習
- 共有参照によって発生する副作用（Side Effect）について学習
- 状態を変更できない不変（Immutable）オブジェクトの特徴について学習
- 値を変更する代わりに新しいオブジェクトを生成する方法について学習

## 3. Stringクラス

- `String`の基本構造、String Pool、文字列の比較について学習
- `String`の不変性と主要な文字列操作メソッドについて学習
- `StringBuilder`を利用した効率的な文字列操作について学習
- メソッドチェイニングの仕組みについて学習

## 4. ラッパークラス・Classクラス

- 基本型とラッパークラス、ボクシング・アンボクシングについて学習
- `valueOf()`、`parseInt()`などラッパークラスの主要メソッドについて学習
- `Class`クラスを利用したクラス情報の取得について学習
- `System`、`Math`、`Random`クラスの基本的な使用方法について学習

## 5. 列挙型 - ENUM

- 文字列による値管理の問題点と型安全性について学習
- 型安全な列挙型パターンと`enum`の基本構造について学習
- `values()`、`valueOf()`、`name()`などEnumの主要メソッドについて学習
- Enumにフィールドやメソッドを持たせ、条件分岐を整理するリファクタリングについて学習
