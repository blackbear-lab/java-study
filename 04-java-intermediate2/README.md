## 1. ジェネリクス - Generic1

- ジェネリクスが必要な理由と、型ごとにクラスを作成する場合のコードの重複について学習
- `Object`型と多態性を利用したコードの重複解消と、その限界について学習
- ダウンキャストによる型変換の手間と、実行時に発生する型変換エラーの問題について学習
- ジェネリクスを利用した汎用的なクラスの定義と、型パラメータ`<T>`の役割について学習
- 型パラメータと型引数の違い、ジェネリッククラスの基本的な使用方法について学習
- コンパイル時の型チェックによる型安全性の確保と、ジェネリクスの活用方法について学習

## 2. ジェネリクス - Generic2

- 型パラメータの制限が必要な理由と、上限境界を指定する方法について学習
- `<T extends クラス名>`を利用した型パラメータの制限と、継承関係による型安全性について学習
- ジェネリックメソッドの定義方法と、ジェネリッククラスとの違いについて学習
- ジェネリックメソッドにおける型引数の指定と、型推論の仕組みについて学習
- ワイルドカード`<?>`の基本概念と、ジェネリックメソッドとの使い分けについて学習
- 上限境界ワイルドカード`<? extends T>`と下限境界ワイルドカード`<? super T>`の特徴について学習
- 型イレイジャー（型消去）の仕組みと、コンパイル後にジェネリクスの型情報が消去されることについて学習
- 演習問題を通して、型パラメータの制限やジェネリックメソッド、ワイルドカードの理解を深めた
