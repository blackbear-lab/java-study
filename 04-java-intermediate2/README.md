## 1. ジェネリクス - Generic1

- ジェネリクスが必要な理由と、型ごとにクラスを作成する場合のコードの重複について学習
- `Object`型と多態性を利用したコードの重複解消と、その限界について学習
- ダウンキャストによる型変換の手間と、実行時に発生する型変換エラーの問題について学習
- ジェネリクスを利用した汎用的なクラスの定義と、型パラメータ`<T>`の役割について学習
- 型パラメータと型引数の違い、ジェネリッククラスの基本的な使用方法について学習
- コンパイル時の型チェックによる型安全性の確保と、ジェネリクスの活用方法について学習

## 2. ジェネリクス - Generic2

- 型パラメータの制限が必要な理由と、上限境界を指定する方法について学習
- `<T extends クラス名>`を利用した型パラメータの制限と、継承関係による型安全性について学習
- ジェネリックメソッドの定義方法と、ジェネリッククラスとの違いについて学習
- ジェネリックメソッドにおける型引数の指定と、型推論の仕組みについて学習
- ワイルドカード`<?>`の基本概念と、ジェネリックメソッドとの使い分けについて学習
- 上限境界ワイルドカード`<? extends T>`と下限境界ワイルドカード`<? super T>`の特徴について学習
- 型イレイジャー（型消去）の仕組みと、コンパイル後にジェネリクスの型情報が消去されることについて学習
- 演習問題を通して、型パラメータの制限やジェネリックメソッド、ワイルドカードの理解を深めた

## 3. コレクションフレームワーク - ArrayList

- 配列の基本構造と、インデックスを利用した要素へのアクセスについて学習
- ビッグオー記法（O記法）の基本概念と、データ数の増加に伴う処理量の変化について学習
- 配列の要素へのアクセスや検索、追加処理における時間計算量について学習
- 配列の先頭・中間・末尾に要素を追加する際の違いと、要素の移動が必要な理由について学習
- 配列を利用した独自の配列リストを実装し、要素数と配列の容量の違いについて学習
- 配列の容量が不足した際に、新しい配列へ要素をコピーして容量を拡張する仕組みについて学習
- 要素の取得・変更・検索と、指定位置への追加・削除機能を実装
- ジェネリクスを適用し、型安全性を備えた汎用的な配列リストの実装について学習
- 自作の配列リストを通して、ArrayListの内部構造と各操作の特徴について理解を深めた

## 4. コレクションフレームワーク - LinkedList

- データと次のノードへの参照を持つノードの基本構造について学習
- ノード同士を参照でつなぎ、連結リストを構成する仕組みについて学習
- 先頭のノードから順番にたどり、各ノードのデータを取得する方法について学習
- ノードを利用した独自の連結リストを実装し、先頭ノードと要素数の管理について学習
- 要素の取得・変更・検索と、指定位置のノードを取得する処理を実装
- 先頭・中間・末尾への要素の追加と、参照の付け替えによるノードの接続について学習
- 要素の削除処理を実装し、削除位置に応じた参照の更新方法について学習
- ジェネリクスを適用し、型安全性を備えた汎用的な連結リストの実装について学習
- 配列リストと連結リストを比較し、要素へのアクセスや追加・削除における時間計算量の違いについて理解を深めた

## 5. コレクションフレームワーク - List

- Listインターフェースを導入し、配列リストと連結リストの共通操作を抽象化する方法について学習
- 具体的な実装クラスではなく、インターフェースに依存する設計について学習
- 依存関係の注入（DI）を利用し、利用するリストの実装を外部から渡す方法について学習
- コンパイル時の依存関係と実行時の依存関係の違いについて学習
- 自作の配列リストと連結リストの性能を比較し、操作や処理位置による違いを確認
- Java標準のListインターフェースと、ArrayList・LinkedListの基本的な使用方法について学習
- Java標準のArrayListとLinkedListの性能を比較し、内部構造による処理の特徴について学習
- リストの選択では、要素へのアクセス方法や追加・削除する位置を考慮する必要があることを理解

## 6. コレクションフレームワーク - ハッシュ（Hash）

- ListとSetの違いを比較し、重複要素の扱いやデータ管理方法について学習
- Setの基本的な仕組みを理解するため、独自のSetを実装する方法について学習
- 配列を利用したSetの実装と、要素の重複確認に必要な検索処理について学習
- ハッシュアルゴリズムの基本概念と、値を配列のインデックスに変換する仕組みについて学習
- ハッシュインデックスを利用した要素の追加・検索処理と、時間計算量の改善について学習
- 値をそのままインデックスとして使用する場合に発生するメモリの無駄について学習
- 剰余演算（%）を利用してハッシュインデックスを計算し、配列の容量を効率的に利用する方法について学習
- 異なる値が同じハッシュインデックスに割り当てられるハッシュ衝突の仕組みについて学習
- ハッシュ衝突を解決するため、同じインデックスに複数の要素を格納する方法について学習
- ハッシュアルゴリズムを通して、検索性能とメモリ使用量の関係について理解を深めた


## 7. コレクションフレームワーク - HashSet

- ハッシュアルゴリズムを応用し、独自のHashSetを実装する方法について学習
- 配列と連結リストを組み合わせ、ハッシュ衝突を処理する仕組みについて学習
- `MyHashSetV1`を実装し、要素の追加・検索・削除処理について学習
- 文字列を数値に変換するハッシュコードの生成方法について学習
- 文字ごとの数値を利用したハッシュコードの計算方法と、その特徴について学習
- Java標準の`hashCode()`メソッドの役割と、ハッシュコードを生成する仕組みについて学習
- `MyHashSetV2`を実装し、`hashCode()`を利用して要素を管理する方法について学習
- 自作のオブジェクトをHashSetに格納し、参照の比較と論理的な等価性の違いについて学習
- `equals()`メソッドをオーバーライドし、オブジェクトの内容に基づいて重複を判定する方法について学習
- `equals()`と`hashCode()`の関係を理解し、等しいオブジェクトは同じハッシュコードを返す必要があることについて学習
- `equals()`のみをオーバーライドした場合に発生する問題と、`hashCode()`も適切に実装する必要性について学習
- ジェネリクスとインターフェースを導入し、型安全性と拡張性を備えたHashSetの設計について学習
- 独自のHashSetの実装を通して、Java標準のHashSetの基本的な内部構造と重複判定の仕組みについて理解を深めた

## 8. コレクションフレームワーク - Set

- Java標準の`Set`インターフェースの特徴と、重複した要素を保持しない仕組みについて学習
- `HashSet`、`LinkedHashSet`、`TreeSet`の違いと、それぞれの特徴について学習
- `HashSet`を利用し、要素の追加・検索・削除と重複判定の方法について学習
- `LinkedHashSet`を利用し、要素の挿入順序を保持する仕組みについて学習
- `TreeSet`を利用し、要素を自然順序や指定した比較条件に従って並べ替える仕組みについて学習
- `TreeSet`の内部構造と、平衡二分探索木を利用したデータ管理について学習
- `HashSet`と`TreeSet`の検索・追加・削除処理における時間計算量の違いについて学習
- `Set`を利用して重複したデータを除去する方法について学習
- 集合演算である和集合・積集合・差集合の基本概念と実装方法について学習
- `addAll()`、`retainAll()`、`removeAll()`を利用した集合演算について学習
- `Set`を活用した検索処理や重複確認処理の最適化について学習
- `List`と`Set`の特徴を比較し、用途に応じた適切なコレクションの選択について学習
- 演習問題を通して、`Set`の基本操作や集合演算、効率的なデータ処理について理解を深めた


## 9. コレクションフレームワーク - Map、Stack、Queue

- `Map`インターフェースの基本概念と、キー（Key）と値（Value）を組み合わせてデータを管理する仕組みについて学習
- `Map`と`List`、`Set`の違いを比較し、それぞれのデータ管理方法について学習
- `Map`ではキーの重複が許可されず、値の重複は許可されることについて学習
- `put()`、`get()`、`remove()`、`containsKey()`などを利用した基本操作について学習
- `keySet()`、`values()`、`entrySet()`を利用してMapのデータを取得する方法について学習
- `HashMap`、`LinkedHashMap`、`TreeMap`の特徴と、データの順序や内部構造の違いについて学習
- `HashMap`がハッシュアルゴリズムを利用してデータを管理する仕組みについて学習
- `TreeMap`がキーを基準にソートされた状態でデータを管理する仕組みについて学習
- スタック（Stack）の基本概念と、後入れ先出し（LIFO）のデータ構造について学習
- スタックにおけるデータの追加・取得・削除処理について学習
- キュー（Queue）の基本概念と、先入れ先出し（FIFO）のデータ構造について学習
- `offer()`、`poll()`、`peek()`を利用したキューの基本操作について学習
- `Deque`インターフェースの特徴と、両端から要素を追加・削除できる仕組みについて学習
- `ArrayDeque`を利用してスタックとキューの両方を実現する方法について学習
- `Deque`と`Stack`、`Queue`の関係を理解し、用途に応じた使い分けについて学習
- 演習問題を通して、`Map`を利用したデータの検索・集計処理について理解を深めた
- `Map`、`Stack`、`Queue`の特徴を比較し、目的に応じた適切なデータ構造の選択について学習

- 拡張for文（for-each文）の仕組みと、`Iterable`を実装したオブジェクトを反復処理できる理由について学習
- Java標準のコレクションが提供する`Iterable`と`Iterator`の使用方法について学習
- `Comparable`インターフェースを利用し、オブジェクトの自然順序を定義する方法について学習
- `compareTo()`メソッドの戻り値によって、オブジェクトの大小関係を判定する仕組みについて学習
- `Comparator`インターフェースを利用し、外部から比較条件を指定する方法について学習
- `compare()`メソッドを利用した比較処理と、`Comparable`との違いについて学習
- `Comparator`を利用して、昇順・降順など複数のソート条件を指定する方法について学習
- `List.sort()`や`Collections.sort()`を利用したリストの並べ替えについて学習
- `Collections`ユーティリティクラスが提供する便利なメソッドと、その活用方法について学習
- コレクションフレームワーク全体のインターフェースと実装クラスの関係について復習
- `List`、`Set`、`Map`、`Queue`、`Deque`の特徴を比較し、用途に応じた適切なデータ構造の選択について理解を深めた
- 演習問題を通して、反復処理やソート、コレクションの基本操作について理解を深めた
