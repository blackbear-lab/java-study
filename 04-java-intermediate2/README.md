## 1. ジェネリクス - Generic1

- ジェネリクスが必要な理由と、型ごとにクラスを作成する場合のコードの重複について学習
- `Object`型と多態性を利用したコードの重複解消と、その限界について学習
- ダウンキャストによる型変換の手間と、実行時に発生する型変換エラーの問題について学習
- ジェネリクスを利用した汎用的なクラスの定義と、型パラメータ`<T>`の役割について学習
- 型パラメータと型引数の違い、ジェネリッククラスの基本的な使用方法について学習
- コンパイル時の型チェックによる型安全性の確保と、ジェネリクスの活用方法について学習

## 2. ジェネリクス - Generic2

- 型パラメータの制限が必要な理由と、上限境界を指定する方法について学習
- `<T extends クラス名>`を利用した型パラメータの制限と、継承関係による型安全性について学習
- ジェネリックメソッドの定義方法と、ジェネリッククラスとの違いについて学習
- ジェネリックメソッドにおける型引数の指定と、型推論の仕組みについて学習
- ワイルドカード`<?>`の基本概念と、ジェネリックメソッドとの使い分けについて学習
- 上限境界ワイルドカード`<? extends T>`と下限境界ワイルドカード`<? super T>`の特徴について学習
- 型イレイジャー（型消去）の仕組みと、コンパイル後にジェネリクスの型情報が消去されることについて学習
- 演習問題を通して、型パラメータの制限やジェネリックメソッド、ワイルドカードの理解を深めた

## 3. コレクションフレームワーク - ArrayList

- 配列の基本構造と、インデックスを利用した要素へのアクセスについて学習
- ビッグオー記法（O記法）の基本概念と、データ数の増加に伴う処理量の変化について学習
- 配列の要素へのアクセスや検索、追加処理における時間計算量について学習
- 配列の先頭・中間・末尾に要素を追加する際の違いと、要素の移動が必要な理由について学習
- 配列を利用した独自の配列リストを実装し、要素数と配列の容量の違いについて学習
- 配列の容量が不足した際に、新しい配列へ要素をコピーして容量を拡張する仕組みについて学習
- 要素の取得・変更・検索と、指定位置への追加・削除機能を実装
- ジェネリクスを適用し、型安全性を備えた汎用的な配列リストの実装について学習
- 自作の配列リストを通して、ArrayListの内部構造と各操作の特徴について理解を深めた

## 4. コレクションフレームワーク - LinkedList

- データと次のノードへの参照を持つノードの基本構造について学習
- ノード同士を参照でつなぎ、連結リストを構成する仕組みについて学習
- 先頭のノードから順番にたどり、各ノードのデータを取得する方法について学習
- ノードを利用した独自の連結リストを実装し、先頭ノードと要素数の管理について学習
- 要素の取得・変更・検索と、指定位置のノードを取得する処理を実装
- 先頭・中間・末尾への要素の追加と、参照の付け替えによるノードの接続について学習
- 要素の削除処理を実装し、削除位置に応じた参照の更新方法について学習
- ジェネリクスを適用し、型安全性を備えた汎用的な連結リストの実装について学習
- 配列リストと連結リストを比較し、要素へのアクセスや追加・削除における時間計算量の違いについて理解を深めた

## 5. コレクションフレームワーク - List

- Listインターフェースを導入し、配列リストと連結リストの共通操作を抽象化する方法について学習
- 具体的な実装クラスではなく、インターフェースに依存する設計について学習
- 依存関係の注入（DI）を利用し、利用するリストの実装を外部から渡す方法について学習
- コンパイル時の依存関係と実行時の依存関係の違いについて学習
- 自作の配列リストと連結リストの性能を比較し、操作や処理位置による違いを確認
- Java標準のListインターフェースと、ArrayList・LinkedListの基本的な使用方法について学習
- Java標準のArrayListとLinkedListの性能を比較し、内部構造による処理の特徴について学習
- リストの選択では、要素へのアクセス方法や追加・削除する位置を考慮する必要があることを理解
