
# Java Study

Javaの基礎から応用までの知識を体系的に学習し、重要な概念や実装方法を整理するためのリポジトリです。

学習した内容をサンプルコードとして実装し、READMEや学習ノートにまとめることで、Javaの理解を深め、実践的なプログラミングスキルの習得を目指しています。

## 学習目標

- Javaの基本文法とオブジェクト指向プログラミングの理解
- クラス、継承、インターフェース、ポリモーフィズムの習得
- Javaの標準ライブラリや主要APIの活用
- ジェネリクスとコレクションフレームワークの理解
- 例外処理と適切なエラーハンドリングの習得
- マルチスレッドと並行処理の仕組みの理解
- Javaの高度な機能や実装方法の習得
- 保守性や可読性を意識したコードの実装

## 学習方法

### 1. 講義による学習

- Javaの基本概念や仕組みについて学習
- 各機能の役割や使用方法を理解
- サンプルコードを通して処理の流れを確認

### 2. サンプルコードの実装

- 学習した内容をJavaコードとして実装
- 実際の動作や出力結果を確認
- 複数の実装方法を比較し、それぞれの違いを理解
- 必要に応じてコードを修正し、動作を検証

### 3. 学習内容の記録

- 各テーマの学習内容を`README.md`に整理
- 重要な概念や注意点を`STUDY_NOTES.md`に記録
- コード例や処理の流れをまとめ、復習に活用

### 4. 復習と理解度の確認

- 学習した内容を自分の言葉で説明
- コードの実行結果を予測
- 資料を見ずにコードを実装
- 理解が不十分な部分を重点的に復習
