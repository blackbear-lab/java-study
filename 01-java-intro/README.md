# Java 入門

Javaの実行方法から、変数、演算子、条件分岐、繰り返し、配列、メソッドまで、プログラミングの基本文法について学習します。

## 学習状況

- [x] Hello World
- [x] 変数
- [x] 演算子
- [x] 条件分岐
- [x] 繰り返し
- [x] スコープと型変換
- [x] 演習 - Scanner
- [x] 配列
- [x] メソッド

※ 提供された講義一覧のセクション2〜10（講義4〜81）を対象に整理。文書の章番号は1から付けている。

---

## 1. Hello World

- JDKと開発環境を準備し、Javaのソースコードを実行する基本的な流れについて学習
- ダウンロードしたソースコードをプロジェクトとして開き、実行する方法について学習
- クラスと`main()`メソッドの基本的な構成について学習
- `System.out.println()`を使用して文字列を出力する方法について学習
- 行コメントとブロックコメントを使い分ける方法について学習
- ソースコード、コンパイル、バイトコード、JVMの関係について理解を深めた

## 2. 変数

- 変数に値を保持し、同じ値を複数の処理で利用する方法について学習
- 変数の宣言、初期化、再代入の違いについて学習
- 整数、浮動小数点数、文字、真偽値を扱う基本的な型について学習
- `String`を使用して文字列を扱う方法について学習
- リテラルと型の関係、値の範囲に応じた型の選択について学習
- 変数名の規則とキャメルケースによる命名について理解を深めた

## 3. 演算子

- 算術演算子を使用した加算、減算、乗算、除算、剰余について学習
- 整数同士の除算と、小数を含む除算の違いについて学習
- `+`による文字列連結と、左からの評価による結果の違いについて学習
- 演算子の優先順位と括弧の使用方法について学習
- 前置・後置のインクリメントとデクリメントの違いについて学習
- 比較演算子、論理演算子、代入演算子の使用方法について学習
- 文字列の内容比較では`equals()`を使用する必要性について理解を深めた

## 4. 条件分岐

- `if`と`else`を使用して、条件によって処理を切り替える方法について学習
- `else if`で複数の条件を順番に判定する方法について学習
- 独立した複数の`if`と、`if`・`else if`による分岐の違いについて学習
- `switch`による値に応じた分岐と`break`の役割について学習
- 三項演算子を使用して条件に応じた値を選択する方法について学習
- 境界値と条件の順序を意識し、判定の漏れや重複を防ぐ方法について理解を深めた

## 5. 繰り返し

- 同じ処理を繰り返す必要性と、ループによる重複の削減について学習
- `while`を使用した条件付きの繰り返しについて学習
- `do-while`によって少なくとも一度実行する繰り返しについて学習
- `break`によるループの終了と、`continue`による次の反復への移行について学習
- `for`の初期化、条件判定、更新処理の流れについて学習
- ネストしたループによる表形式の出力や繰り返し処理について学習
- 無限ループと反復回数のずれを防ぐための条件設定について理解を深めた

## 6. スコープと型変換

- ブロックによってローカル変数の有効範囲が決まることについて学習
- 変数を必要な範囲だけで宣言し、理解しやすいコードにする方法について学習
- 数値型の自動型変換と明示的な型変換について学習
- 縮小変換による小数部分の切り捨てや値の変化について学習
- 演算前の型変換と演算後の型変換で、結果が異なる場合について学習
- 整数演算のオーバーフローと、計算時の型を意識する必要性について理解を深めた

## 7. 演習 - Scanner

- `Scanner`と`System.in`を使用して標準入力を読み取る方法について学習
- 整数、小数、文字列を入力するメソッドの使い分けについて学習
- 数値入力と行入力を組み合わせる際の注意点について学習
- 入力値を使用した計算や条件分岐の実装について学習
- ループと終了条件を組み合わせた対話型処理について学習
- 合計、平均、値の交換などの演習を通して基本文法の活用について理解を深めた

## 8. 配列

- 同じ型の複数の値を、配列でまとめて管理する方法について学習
- 配列の宣言、生成、初期化、要素へのアクセスについて学習
- 添字が0から始まり、有効範囲が`length - 1`までであることについて学習
- 配列とループを組み合わせ、重複する処理を整理する方法について学習
- 二次元配列とネストしたループによるデータ処理について学習
- 拡張for文による走査と、添字付きfor文との使い分けについて学習
- 合計、平均、最大値などの演習を通して配列の基本的な活用について理解を深めた

## 9. メソッド

- 重複する処理をメソッドに抽出し、再利用する方法について学習
- メソッドの定義、呼び出し、引数、戻り値の関係について学習
- `void`と値を返すメソッドの違いについて学習
- Javaの引数渡しが値渡しであり、基本型の引数への再代入が呼び出し元を変更しないことについて学習
- 引数・戻り値と型変換の関係について学習
- 引数の型・数・並びによるメソッドのオーバーロードについて学習
- 責務が明確なメソッドに分割し、読みやすく変更しやすいコードにする方法について理解を深めた
