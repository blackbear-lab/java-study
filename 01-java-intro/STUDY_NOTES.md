### 実行までの流れ

1. JDKを用意し、開発環境で使用するJDKを設定する
2. Javaのソースファイルを作成する、または既存のプロジェクトを開く
3. ソースコードをコンパイルする
4. JVM上でプログラムを実行する

- JDKは、コンパイラなどの開発用ツールを含む
- `javac`はJavaソースをバイトコードへコンパイルする
- JVMはバイトコードを実行するための仕組み
- IDEは編集、コンパイル、実行などをまとめて支援する
- JVMの実装は実行環境ごとに異なり、ネイティブ機能などには環境依存性もある

### 最初のプログラム

```java
public class HelloJava {
    public static void main(String[] args) {
        System.out.println("Hello Java");
        System.out.println("Javaの学習を始めます");
    }
}
```

**出力例**

```text
Hello Java
Javaの学習を始めます
```

- この基本形では、ファイル名を`HelloJava.java`にする
- `main()`から処理を開始し、基本的には上から順番に実行する
- Javaは大文字と小文字を区別する
- 文の終わりには通常`;`を付け、処理のまとまりは`{}`で表す
- `println()`は末尾で改行し、`print()`は自動では改行しない

### コメント


- コメントは処理として実行されない
- ブロックコメントを入れ子にしない
- コードをそのまま言い換えるだけでなく、理由や前提を記録する
- ダウンロードしたコードでは、プロジェクトのルートとJDKの設定を確認してから実行する

### 宣言・初期化・再代入

```java
int score;       // 宣言
score = 80;      // 最初の代入による初期化
score = 95;      // 再代入
int count = 3;   // 宣言と初期化
System.out.println(score); // 95
```

- 変数は型と名前を持ち、値を保持する
- `=`は等しいことの判定ではなく、右辺の値を左辺に代入する演算子
- ローカル変数は、値を読み取る前に初期化する必要がある
- 再代入は過去の出力や、以前に別の変数へコピーした値を変更しない

### 主な型とリテラル

| 型 | 主な用途 | 例 |
| --- | --- | --- |
| `byte` | 8ビットの符号付き整数 | `byte level = 10;` |
| `short` | 16ビットの符号付き整数 | `short count = 1000;` |
| `int` | 32ビットの符号付き整数 | `int age = 20;` |
| `long` | 64ビットの符号付き整数 | `long population = 3000000000L;` |
| `float` | 単精度の浮動小数点数 | `float ratio = 0.5F;` |
| `double` | 倍精度の浮動小数点数 | `double price = 12.5;` |
| `char` | UTF-16のコード単位 | `char grade = 'A';` |
| `boolean` | 真偽値 | `boolean passed = true;` |
| `String` | 文字列を扱う参照型 | `String name = "田中";` |

- 整数リテラルは通常`int`、小数リテラルは通常`double`として扱われる
- `long`のリテラルでは見やすい大文字の`L`を使用する
- `char`はシングルクォート、`String`はダブルクォートで囲む
- 一つの`char`ですべてのUnicode文字を表せるわけではない
- 浮動小数点数では、小数を正確に表せず誤差が出る場合がある

### 命名の注意点

- 変数名は`studentCount`のようなキャメルケースを基本にする
- 数字で始めたり、`class`などの予約語を使ったりできない
- 大文字・小文字は区別される
- `a`や`b`より、用途が分かる名前を選ぶ

### 算術演算と文字列連結

```java
System.out.println(7 + 2);      // 9
System.out.println(7 - 2);      // 5
System.out.println(7 * 2);      // 14
System.out.println(7 / 2);      // 3
System.out.println(7 % 2);      // 1
System.out.println(7 / 2.0);    // 3.5
System.out.println("合計: " + 1 + 2);   // 合計: 12
System.out.println("合計: " + (1 + 2)); // 合計: 3
```

- 整数同士の除算は、小数部分を0に近い方向へ切り捨てる
- 整数を0で割ると`ArithmeticException`になる
- 浮動小数点数の0除算は整数と異なり、無限大やNaNになる場合がある
- `+`に文字列が含まれると、文字列連結として扱われる
- 掛け算・割り算などの優先順位を理解しつつ、意図を明確にする括弧を使用する

### 前置と後置

```java
int a = 1;
int before = ++a; // aを2にして、2を代入
int after = a++;  // 2を代入して、aを3にする
```

- 単独の文で使う場合、どちらも変数を1増やす
- 他の処理を同じ式に詰め込むと評価順序が分かりにくくなるため、簡潔に記述する

### 比較・論理・代入

| 分類 | 演算子 | 意味 |
| --- | --- | --- |
| 比較 | `==`、`!=` | 等しい・等しくない |
| 比較 | `<`、`<=`、`>`、`>=` | 大小関係 |
| 論理 | `&&` | 両方の条件がtrue |
| 論理 | `\|\|` | 少なくとも一方がtrue |
| 論理 | `!` | 真偽値の反転 |
| 代入 | `=`、`+=`、`-=`、`*=`、`/=`、`%=` | 代入・演算結果の代入 |

- `&&`は左辺が`false`、`||`は左辺が`true`なら右辺を評価しない
- `0 < age < 20`とは書けず、`0 < age && age < 20`と書く
- `String`の内容は`equals()`で比較する。`==`は参照の同一性を比較する
- 文字列の例：`"Java".equals(language)`
- 複合代入は左辺型への変換を含むため、一般に単純な書き換えと完全に同じではない

### 一つの分岐と独立した判定

```java
int score = 85;
if (score >= 90) {
    System.out.println("A");
} else if (score >= 80) {
    System.out.println("B");
} else {
    System.out.println("C");
}
```

- `if`・`else if`の連続では、最初に成立した分岐だけを実行する
- 上の例では`B`を出力する
- 小さい基準を先に判定すると、大きい基準へ到達しない場合がある
- 複数の独立した`if`は、それぞれの条件が成立すれば複数回実行する
- 複数割引の同時適用など、独立した条件では複数の`if`が適する場合がある

### switchと三項演算子

```java
int menu = 2;
switch (menu) {
    case 1:
        System.out.println("登録");
        break;
    case 2:
        System.out.println("一覧");
        break;
    default:
        System.out.println("該当なし");
}

int age = 20;
String category = age >= 18 ? "成人" : "未成年";
```

| 方法 | 適した処理 | 注意点 |
| --- | --- | --- |
| if | 範囲や複数条件の判定 | 条件の順序・重複を確認する |
| switch | 値ごとの分岐 | コロン形式ではbreakの省略によるフォールスルーに注意 |
| 三項演算子 | 条件に応じた値の選択 | 複雑な入れ子を避ける |

- 上の例は従来のコロン形式。矢印形式のswitchとは動作の規則が異なる
- 三項演算子は`条件 ? trueの場合の値 : falseの場合の値`と記述する
- 境界の直前・境界上・直後の値で、想定どおりの分岐になるか確認する

**復習用演習**

- 点数から評価を決める。79、80、89、90で結果を確認する
- 会員割引と期間限定割引を、独立した条件として実装する

### while・do-while・forの比較

```java
int count = 1;
while (count <= 3) {
    System.out.println(count);
    count++;
}

int number = 5;
do {
    System.out.println(number); // 条件がfalseでも一度は実行
} while (number < 3);

int sum = 0;
for (int i = 1; i <= 5; i++) {
    sum += i;
}
System.out.println(sum); // 15
```

| 構文 | 条件確認 | 主な用途 |
| --- | --- | --- |
| while | 実行前 | 終了条件まで繰り返す |
| do-while | 実行後 | 最低一度実行する |
| for | 初期化後と各更新後 | 回数や添字を管理する |

- `for`は初期化 → 条件 → 本体 → 更新 → 条件の順に進む
- 条件を変化させる処理がないと、意図せず無限ループになる場合がある
- `do-while`の末尾には`;`が必要

### breakとcontinue

```java
for (int i = 1; i <= 10; i++) {
    if (i == 3) {
        continue;
    }
    if (i == 6) {
        break;
    }
    System.out.println(i); // 1、2、4、5
}
```

- `break`は、この例では最も内側のループを終了する
- `continue`は本体の残りを飛ばして次の反復へ進む
- `for`の`continue`では更新式へ進む
- `while`で更新処理より前に`continue`すると、更新されず無限ループになる場合がある

### ネストしたループ

```java
for (int row = 1; row <= 2; row++) {
    for (int column = 1; column <= 3; column++) {
        System.out.print(row + "," + column + " ");
    }
    System.out.println();
}
```

- 外側が一度進むたびに、内側のループを最初から実行する
- この例では内側の本体を合計6回実行する
- 回数が増えやすいため、ループごとの役割と終了条件を明確にする

**復習用演習**

- 1から指定値までの合計を計算する
- 二重ループで九九や三角形を出力する

### ローカル変数の有効範囲

```java
int outer = 10;
if (outer > 0) {
    int inner = 20;
    System.out.println(outer + inner);
}
// System.out.println(inner); // スコープ外でコンパイルエラー
```

- ブロック内で宣言した変数は、宣言位置からそのブロックの終わりまでを基本的な有効範囲とする
- `for (int i = 0; ... )`の`i`は、そのfor文の外では利用できない
- スコープが重なるローカル変数を同名で宣言することはできない
- 使用する場所の近くで宣言すると、値を追う範囲と誤操作の可能性を減らせる
- スコープを狭める目的を、必ず実行速度が上がるという説明に置き換えない

### 自動変換と明示的な変換

```java
int integer = 10;
double decimal = integer; // 自動変換：10.0
double source = 3.9;
int truncated = (int) source; // 明示的な変換：3

System.out.println(5 / 2);         // 2
System.out.println((double) 5 / 2); // 2.5
System.out.println((double) (5 / 2)); // 2.0
```

- 整数除算後に変換しても、すでに失われた小数部分は戻らない
- 浮動小数点数から整数への変換は、通常の範囲では0に近い方向へ小数部分を切り捨てる
- `int`から`byte`などへの縮小変換では、値が変化する場合がある
- 拡大変換でも`long`から`double`など、精度を失う組み合わせがある
- `byte`、`short`、`char`同士の通常の算術演算は、基本的に`int`へ昇格する

### 計算時の型とオーバーフロー

```java
int a = 50000;
int b = 50000;
long incorrect = a * b;        // intで計算した時点でオーバーフロー
long correct = (long) a * b;   // longで計算：2500000000
```

- 代入先が`long`でも、右辺が自動的にlong演算になるとは限らない
- 必要に応じて、演算前に片方の値を適切な型へ変換する
- 整数の通常の加算・乗算は、範囲を超えても自動的には例外にならない

### 標準入力を読み取る

```java
import java.util.Scanner;

public class ScannerMain {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        System.out.print("年齢: ");
        int age = scanner.nextInt();
        scanner.nextLine(); // 数値の後に残った行末までを消費
        System.out.print("名前: ");
        String name = scanner.nextLine();
        System.out.println(name + "さんは" + age + "歳です");
    }
}
```

| メソッド | 主な用途 |
| --- | --- |
| `nextInt()` | 整数のトークンを読み取る |
| `nextDouble()` | 小数のトークンを読み取る |
| `next()` | 空白などで区切られた一つのトークンを読み取る |
| `nextLine()` | 現在位置から行末までを読み取る |
| `hasNextInt()` | 次を整数として読み取れるか確認する |

- `nextInt()`の直後の`nextLine()`は、残った行末までを読み取り、空文字になる場合がある
- 入力の設計に合わせ、残りの行を消費するか、行単位で読み取って変換する
- 数値として解釈できない入力を`nextInt()`に渡すと、`InputMismatchException`になる
- 不正入力を再入力させる場合は、読み取れなかったトークンなどを消費しないと同じ入力を繰り返し判定する
- `Scanner`を閉じると元の`System.in`も閉じるため、その後の標準入力の利用に注意する

### 終了条件を持つ入力ループ

```java
Scanner scanner = new Scanner(System.in);
int sum = 0;
int count = 0;
while (true) {
    System.out.print("整数を入力（-1で終了）: ");
    int value = scanner.nextInt();
    if (value == -1) {
        break;
    }
    sum += value;
    count++;
}
if (count > 0) {
    System.out.println("合計: " + sum);
    System.out.println("平均: " + (double) sum / count);
} else {
    System.out.println("データがありません");
}
```

- この断片では`java.util.Scanner`をimportし、整数が入力されることを前提にする
- 終了を表す値は合計や件数へ含めない
- データが0件の場合は、平均を計算しない
- `-1`を実データとして使用したい場合は、別の終了方法を選ぶ

**復習用演習**

- 一時変数を使って二つの値を交換する
- 単価と数量を入力し、合計金額を表示する
- メニュー番号で登録・表示・終了を切り替える

### 宣言・生成・アクセス

```java
int[] scores = new int[3];
scores[0] = 80;
scores[1] = 90;
scores[2] = 100;

int sum = 0;
for (int i = 0; i < scores.length; i++) {
    sum += scores[i];
}
System.out.println("平均: " + (double) sum / scores.length); // 90.0
```

- `int[] scores = {80, 90, 100};`のようにまとめて初期化することもできる
- 配列の長さは生成後に変更できない
- 添字は0から始まり、長さ3なら有効な添字は0〜2
- 範囲外の添字では`ArrayIndexOutOfBoundsException`になる
- `length`は配列のフィールドであり、`length()`とは書かない
- 配列要素には、数値なら0、booleanならfalse、参照型ならnullなどの初期値が設定される

### 配列は参照型

```java
int[] first = {1, 2};
int[] second = first;
second[0] = 99;
System.out.println(first[0]); // 99
```

- 変数へ配列の参照を代入しても、要素全体が自動的に複製されるわけではない
- 配列変数が`null`の状態で要素や`length`へアクセスすると、`NullPointerException`になる

### 二次元配列

```java
int[][] matrix = {
    {1, 2, 3},
    {4, 5, 6}
};
for (int row = 0; row < matrix.length; row++) {
    for (int column = 0; column < matrix[row].length; column++) {
        System.out.print(matrix[row][column] + " ");
    }
    System.out.println();
}
```

- Javaの二次元配列は、配列を要素として持つ配列
- 外側の`length`は行数で、各行の`length`がその行の要素数
- 行ごとに長さが異なる配列も作成できる
- すべての行が同じ長さであることを、常に前提にしない

### 拡張for文

```java
int[] values = {10, 20, 30};
for (int value : values) {
    System.out.println(value);
}
for (int value : values) {
    value = 0; // ループ変数への代入であり、配列要素は変わらない
}
```

| 方法 | 適した用途 |
| --- | --- |
| 添字付きfor文 | 要素の書き換え、添字の利用、逆順の処理 |
| 拡張for文 | 全要素を順番に読み取る処理 |

- 参照型の要素の場合、コピーした参照から参照先の状態を変更することはできる
- 空の配列の平均や最大値を求める場合は、データがない場合の扱いを決める
- 最大値を0で初期化すると、負数だけの配列で正しい結果にならない場合がある

**復習用演習**

- 入力した整数を配列に格納し、合計・平均・最大値・最小値を求める
- 逆順で表示する
- 学生ごとの複数科目の点数を二次元配列で管理する

### 定義と呼び出し

```java
public class MethodMain {
    public static void main(String[] args) {
        int result = add(10, 20);
        printResult(result);
    }

    static int add(int first, int second) {
        return first + second;
    }

    static void printResult(int value) {
        System.out.println("結果: " + value);
    }
}
```

- 呼び出し側から渡す値を引数、定義側で受け取る変数を仮引数と呼ぶ
- 戻り値の型は、呼び出し元へ返す値の型を表す
- `void`は値を返さないことを表す
- 値を返すメソッドは、正常に終了する各経路で適切な値を返す必要がある
- `return`を実行すると、そのメソッドの処理を終了する
- `void`のメソッドでは、`return;`で途中終了できる
- この基本形では、`static main()`から同じクラスのstaticメソッドを直接呼び出している

### Javaの引数渡しは値渡し

```java
static void change(int number) {
    number = 100;
}

// main()内の例
// int original = 10;
// change(original);
// System.out.println(original); // 10
```

- 仮引数へ、呼び出し時の値がコピーされる
- 仮引数に別の値を代入しても、呼び出し元の変数そのものは変わらない
- 計算結果を受け取りたい場合は、戻り値を返して呼び出し元で代入する
- 配列などの参照型では参照の値がコピーされるため、同じ配列の要素を変更することはできる
- 参照型の場合も値渡しであり、呼び出し元の変数への再代入を直接行う仕組みではない

### メソッドと型変換

```java
static void printDouble(double value) {
    System.out.println(value);
}

// printDouble(10); // intからdoubleへ自動変換して渡す
```

- 引数には、仮引数型へ許可された変換が可能な値を渡す
- `double`の値を`int`の仮引数に渡す場合などは、必要に応じて明示的に変換する
- 型変換によって情報が失われないかを確認する

### オーバーロード

```java
static int add(int a, int b) {
    return a + b;
}

static int add(int a, int b, int c) {
    return a + b + c;
}

static double add(double a, double b) {
    return a + b;
}
```

| 違い | オーバーロードの定義に使えるか |
| --- | --- |
| 引数の数 | 使える |
| 引数の型 | 使える |
| 異なる型の並び順 | 使える |
| 引数の名前だけ | 使えない |
| 戻り値の型だけ | 使えない |

- メソッド名と仮引数の型の並びを基準に区別する
- 引数の型に合うメソッドがコンパイル時に選択される
- 完全に一致する候補や型変換の規則によって選ばれるが、複数の候補が競合すると曖昧になる場合もある
- 同じ名前には関連する責務を割り当て、無関係な処理をまとめない
