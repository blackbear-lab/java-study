## 1. クラスとデータ

- プロジェクトの環境を構成し、Javaのクラスを作成・実行する基本的な流れについて学習
- 名前、年齢、成績などの関連するデータを別々に管理した場合の問題について学習
- クラスを使用して関連するデータを一つにまとめる方法について学習
- フィールドを定義し、オブジェクトの状態を表現する方法について学習
- `new`を使用してインスタンスを生成し、参照を変数に代入する方法について学習
- クラス、オブジェクト、インスタンスの関係について学習
- オブジェクトの配列を使用して複数のデータを管理する方法について学習
- 配列と繰り返し処理によるリファクタリングを通して、コードの重複を減らす方法について理解を深めた

## 2. 基本型と参照型

- 基本型は値を保持し、参照型はオブジェクトなどへの参照を保持することについて学習
- 変数への代入では、基本型・参照型のどちらも変数が持つ値がコピーされることについて学習
- 参照をコピーした複数の変数が、同じオブジェクトを参照する仕組みについて学習
- Javaの引数渡しは値渡しであり、参照型の場合も参照の値がコピーされることについて学習
- メソッド内でのオブジェクトの変更と、引数変数への再代入の違いについて学習
- フィールドや配列要素のデフォルト初期化と、ローカル変数の初期化の違いについて学習
- `null`と`NullPointerException`の原因・対処方法について理解を深めた

## 3. オブジェクト指向プログラミング

- 手続き型のコードから、データの集約とメソッドの抽出を行う流れについて学習
- 状態と、その状態を操作する振る舞いを同じクラスにまとめる方法について学習
- インスタンスメソッドを使用して、オブジェクト自身の状態を変更する方法について学習
- 呼び出し元が内部処理の詳細を意識せず、公開された操作を利用する利点について学習
- 音楽プレイヤーなどの学習用例を通して、責務をオブジェクトに割り当てる考え方について理解を深めた

## 4. コンストラクタ

- オブジェクト生成時の初期化処理を統一する必要性について学習
- `this`で現在のインスタンスを参照し、フィールドと引数を区別する方法について学習
- コンストラクタの定義と、`new`による呼び出しについて学習
- コンストラクタを一つも宣言しない場合に、デフォルトコンストラクタが追加されることについて学習
- コンストラクタのオーバーロードと`this()`による初期化処理の共通化について理解を深めた

## 5. パッケージ

- パッケージを使用してクラスを分類し、名前の衝突を避ける方法について学習
- `package`宣言とディレクトリ構成の関係について学習
- 完全修飾名と`import`によるクラスの利用方法について学習
- パッケージ名の命名規則と、機能・責務に応じた構成について学習
- 同名クラスの扱いと、パッケージとアクセス制御の関係について理解を深めた

## 6. アクセス修飾子

- `private`、パッケージアクセス、`protected`、`public`の違いについて学習
- フィールド、メソッド、クラスに対するアクセス制御について学習
- 通常のトップレベルクラスで指定できるアクセス範囲について学習
- データを直接公開せず、必要な操作を通して状態を変更するカプセル化について学習
- アクセス修飾子を使用して、不正な状態変更や内部実装への依存を防ぐ方法について理解を深めた

## 7. Javaのメモリ構造とstatic

- メソッド領域、スタック領域、ヒープ領域の基本的な役割について学習
- スタックとキューの取り出し順序を比較し、LIFOとFIFOの違いについて学習
- メソッド呼び出しとスタックフレーム、オブジェクトと参照の関係について学習
- インスタンス変数と`static`変数の違いについて学習
- `static`メソッドが特定のインスタンスに属さないことについて学習
- `static`な文脈からインスタンスメンバーを利用するには、対象の参照が必要になることについて学習
- クラス名によるアクセスと、共有する状態の設計上の注意点について理解を深めた

## 8. final

- `final`によって変数への再代入を禁止する方法について学習
- ローカル変数、引数、フィールドに`final`を指定する場合の違いについて学習
- `static final`による定数の表現と命名規則について学習
- `final`な参照と、参照先オブジェクトの変更可能性の違いについて学習
- 再代入の禁止と不変オブジェクトを区別する必要性について理解を深めた

## 9. 継承

- `extends`を使用して、共通する状態と振る舞いを親クラスにまとめる方法について学習
- 継承による機能の追加と、is-a関係の意味について学習
- 親クラスの状態も子クラスのインスタンスの一部として扱われることについて学習
- メソッドのオーバーライドと`@Override`の使用方法について学習
- 継承とアクセス制御の関係について学習
- `super`による親クラスのメソッド呼び出しと、`super()`によるコンストラクタ呼び出しについて学習
- オーバーロードとオーバーライドの違いについて理解を深めた

## 10. 多態性1

- 親型の変数で子クラスのインスタンスを参照する多態的参照について学習
- アップキャストとダウンキャストの違いについて学習
- 参照型によって呼び出せるメンバーが決まることについて学習
- 不正なダウンキャストによって`ClassCastException`が発生することについて学習
- `instanceof`を使用して型を確認する方法について学習
- オーバーライドされたメソッドは、実際のインスタンスに応じて選択されることについて学習
- フィールドの参照とメソッドの動的な選択を区別する必要性について理解を深めた

## 11. 多態性2

- 共通の親型、配列、メソッド引数を利用し、重複する処理を共通化する方法について学習
- 抽象クラスと抽象メソッドの役割について学習
- 抽象クラスを直接インスタンス化できないことについて学習
- インターフェースによって、実装が満たすべき契約を定義する方法について学習
- 複数のインターフェースの実装と、クラスの単一継承との違いについて学習
- クラスの継承とインターフェースの実装を組み合わせ、状態の共有と役割の表現を分離する方法について理解を深めた

## 12. 多態性と設計

- オブジェクト間の協調と、役割・実装を分離する設計について学習
- 利用する側が具象クラスではなく、インターフェースに依存する構成について学習
- 実装を外部から渡し、利用する側の変更を減らす方法について学習
- OCP（Open-Closed Principle）の基本概念について学習
- 新しい実装を追加して機能を拡張し、既存の利用側コードの変更を抑える設計について学習
- 型ごとの条件分岐と、多態性を利用した処理の比較について学習
- 演習を通して、変更が発生する箇所を意識したオブジェクト指向設計について理解を深めた
